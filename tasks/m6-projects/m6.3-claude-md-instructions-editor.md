# M6.3 CLAUDE.md instructions editor

- status: done
- depends: M6.2
- files: `app/src/project/InstructionsDialog.{h,cpp}`, `app/src/MainFrame.cpp`
- goal: Users edit project instructions without leaving the app.
- spec:
  1. Project > Instructions… opens a dialog with a monospace multiline `wxTextCtrl` loaded from `<root>/CLAUDE.md` (empty if missing).
  2. Save writes atomically. Cancel discards.
  3. After saving, show a note that the change applies to new chats. Running sessions loaded the old file.
- done when:
  - [ ] Manual: add "Always answer in French" and start a new chat. The reply is in French. An old chat is unchanged.
- verify: manual run.

- notes: Load/save live in app/src/project/Instructions.{h,cpp} (no wx). Save writes a uniquely named CLAUDE.md.<random>.tmp next to the file and renames it over it, copying the old permissions; a symlinked CLAUDE.md is followed so the link stays and its target gets the text; a failed save shows an error and keeps the dialog open. The sidecar is not told about a save: new chats start with setting_sources=["project"] in the project folder and read CLAUDE.md themselves. A CLAUDE.md that is not valid UTF-8 is refused with an error instead of being opened, so a save cannot wipe it. Ctrl+S also saves in the dialog. The note says open chats "may" keep the old instructions: a chat resumed after an interrupt or crash re-reads CLAUDE.md. The dialog title ("Instructions for "<folder>"") is not visible in the screenshots because Xvfb runs without a window manager.
