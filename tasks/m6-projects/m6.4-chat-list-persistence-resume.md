# M6.4 Chat list, persistence, resume

- status: todo
- depends: M6.2, M5.2
- files: `app/src/chat/ChatList.{h,cpp}`, `app/src/chat/ChatPanel.cpp`, `app/src/project/Project.cpp`
- goal: Chats survive restarts and pick up where they left off.
- spec:
  1. A chat list sits above the message view: a dropdown of chats by `updated` desc, plus "New chat", "Rename", and "Delete".
  2. New chat: generate a UUID, add it to `project.json`, send `new_chat`. The title is the first 60 chars of the first user message.
  3. After every user message and every `result`, append to `.reader/chats/<id>.jsonl` and update `updated`. Store the `session_id` from the first `result`.
  4. Selecting a chat loads its transcript from JSONL into the view and sends `resume_chat {chat_id, session_id}`.
  5. Delete removes the entry and its JSONL after a confirmation dialog. It does not touch Claude Code's own session files.
  6. If resume fails (`error` on resume), keep the transcript visible, mark the chat "cannot resume", and offer "Continue in new chat". That creates a new chat whose first prompt includes the last 20 transcript messages as context.

  - [ ] Manual: chat, restart, select the chat. The transcript shows, and a follow-up question refers to earlier answers correctly.
