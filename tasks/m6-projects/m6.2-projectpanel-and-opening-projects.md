# M6.2 ProjectPanel and opening projects

- status: todo
- depends: M6.1, M2.5, M5.1
- files: `app/src/project/ProjectPanel.{h,cpp}`, `app/src/MainFrame.cpp`
- goal: Users open a folder as a project and browse its PDFs.
- spec:
  1. File > Open Project (Ctrl+Shift+O) uses `wxDirDialog`. Add recent projects to the File menu.
  2. `ProjectPanel`: a `wxTreeCtrl` of folders and PDFs. Activating a PDF opens it in `PdfView`.
  3. Refresh with `wxFileSystemWatcher` on add, remove and rename. Debounce 300 ms.
  4. Opening a project sends `open_project {path}` to the sidecar.
  5. Opening a single PDF outside any project opens its parent folder as an unsaved project: no `.reader/` is created and chats are not persisted. The panel header says "Unsaved project" with a "Save as project" button that creates `.reader/`.
  6. On app start, reopen the last project and its `open_file`.
- done when:
  - [ ] Manual: open a folder, see PDFs, open one. Add a PDF in a file manager and it appears. Restart and the same project and file come back.
