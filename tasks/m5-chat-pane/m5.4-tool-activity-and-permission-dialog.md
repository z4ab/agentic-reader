# M5.4 Tool activity and permission dialog

- status: done
- depends: M5.2
- files: `app/src/chat/ChatPanel.cpp`, `app/src/chat/PermissionDialog.{h,cpp}`
- goal: Users see what Claude does and approve anything beyond reading.
- spec:
  1. `tool_use` renders as a single grey line in the message, for example "Read papers/attention.pdf pages 10-12". Format the common tools (Read, Glob, Grep, Write, Edit, Bash, WebFetch, WebSearch) and fall back to `name` plus compact JSON.
  2. `permission_request` opens `PermissionDialog`, which is modal to the frame. It shows the tool, a formatted input, and Allow / Deny buttons. Deny is the default button and Esc means deny.
  3. The reply goes back as `permission_reply`.
  4. If the sidecar restarts while the dialog is open, close the dialog without replying.
- done when:
  - [ ] Manual: ask Claude to "write a summary to notes.md". The dialog appears. Deny means no file is created. Allow means the file is created.
- verify: manual run in a scratch project folder.
