# M5.2 ChatPanel UI

- status: todo
- depends: M5.1
- files: `app/src/chat/ChatPanel.{h,cpp}`, `app/src/chat/Markdown.{h,cpp}`, `tests/test_markdown.cpp`, `app/src/MainFrame.cpp`
- goal: A usable chat interface with streamed replies.
- spec:
  1. Layout top to bottom: message view, context chip (M5.3), multiline input, buttons (Send, Stop).
  2. Message view: `wxHtmlWindow`. Convert assistant Markdown to HTML with md4c (`md_html`) in `Markdown.cpp`. Escape user text as plain text. Supported formatting is what `wxHtmlWindow` renders: headings, lists, bold, italics, code, links. Links open in the system browser via `wxLaunchDefaultBrowser`.
  3. Streaming: append `text_delta` to the current assistant message buffer. Re-render with a 50 ms `wxTimer` throttle, not on every delta. Keep the view scrolled to the bottom unless the user scrolled up.
  4. Enter sends. Shift+Enter inserts a newline. Disable Send while a reply is running. Enable Stop only while running. Stop sends `interrupt`.
  5. `result` ends the message and shows cost and tokens in small grey text under it.
  6. `error` shows a red inline notice. Kind-specific actions come in M7.3.
  7. Replace the right placeholder pane in `MainFrame` with `ChatPanel`. For now, the chat uses the open PDF's folder as the project (M6 replaces this).

  - [ ] Markdown tests: a heading, a code block, and raw HTML in input are rendered or escaped as expected.
  - [ ] Manual: ask a question, watch the text stream, stop a long reply mid-stream.
- verify: `ctest -R markdown` plus manual run.
