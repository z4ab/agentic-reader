# M9.2 Chat navigation shortcuts

- status: done
- depends: M9.1
- files: `app/src/chat/ChatList.{h,cpp}`, `app/src/chat/ChatPanel.{h,cpp}`, `app/src/MainFrame.cpp`, `tests/test_chat_list.cpp`, `tests/acceptance/m9.2.steps`
- goal: Move between the project's chats with the keyboard.
- spec:
  1. `chatlist::neighbor(const std::vector<std::string>& ids, const std::string& current, int step)` returns the id `step` places from `current` in `ids`, wrapping around both ends. It returns `current` unchanged when `ids` has fewer than two entries or does not contain `current` (a single entry cannot move, and an unknown id must not move).
  2. `ChatPanel::nextChat()` selects the chat after the current one in the dropdown order (newest first); `prevChat()` selects the one before it. Both wrap. They are no-ops while a reply runs (the dropdown is disabled then) and when there is no project.
  3. Ctrl+Tab is Next Chat, Ctrl+Shift+Tab is Previous Chat. The Chat menu gains two items with those labels.
  4. Because wx and GTK reserve Ctrl+Tab in some controls, wire the two keys with a frame `wxEVT_CHAR_HOOK` (or a frame `wxAcceleratorTable`), not only a menu accelerator, and confirm they fire when the chat input and the PDF view have focus.
  5. Selecting a chat by key is the same as picking it in the dropdown: the transcript loads and `resume_chat`/`new_chat` is sent once per sidecar process (M6.4). The selection is reflected in the dropdown.

  - [x] While a reply runs the two keys do nothing and the dropdown stays put.
