  3. Additions to the plan's protocol:
     - every inbound message has an optional `seq` int that is echoed back in an error, so the app can match failures
     - outbound `chat_started {chat_id, session_id|null}` answers `new_chat` and `resume_chat`
     - `new_chat` carries the app-chosen `chat_id` (UUID string)
  4. `decode(line: str) -> Inbound` raises `ProtocolError` on bad JSON, unknown type, or missing fields. `encode(msg: Outbound) -> str` returns one line with no embedded newlines.
  5. Write `sidecar/PROTOCOL.md` listing every message with its fields and one example line. The C++ side (M5.1) implements against this file.
  6. Add a `sidecar` job to CI: ubuntu only, install, pytest.
