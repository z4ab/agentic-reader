# M4.4 Reader context, interrupt, permissions

- status: todo
- depends: M4.3
- files: `sidecar/reader_sidecar/context.py`, `sidecar/reader_sidecar/permissions.py`, `sidecar/reader_sidecar/chats.py`, `sidecar/tests/test_context.py`, `sidecar/tests/test_permissions.py`
- goal: Every prompt carries what the user is looking at. Users can stop replies and approve tools.
- spec:
  1. `build_prefix(context) -> str` produces the `<reader_context>` block from the plan. Paths are relative to the project root. Pages are 1-based. The selection is capped at 8,000 chars with "[truncated]" appended. Omit lines whose values are missing. With no context at all, add no block.
  2. `interrupt {chat_id}` calls `client.interrupt()`. The running response ends with its normal `result`, or `error {kind:"interrupted"}` if the SDK raises.
  3. `can_use_tool(tool_name, input, ctx)`:
     - create `req_id` (UUID), store an `asyncio.Future`, send `permission_request {req_id, chat_id, tool, input}`
     - await the future with a 5-minute timeout. A timeout counts as deny.
     - `permission_reply {req_id, allow}` resolves the future
     - return `PermissionResultAllow()` or `PermissionResultDeny(message="User denied")`
  4. Deny all pending requests when a chat closes.
