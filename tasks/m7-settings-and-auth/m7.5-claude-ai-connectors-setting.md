# M7.5 Setting for claude.ai connectors

- status: todo
- depends: M7.2
- files: `app/src/settings/Settings.{h,cpp}`, `app/src/settings/SettingsDialog.{h,cpp}`, `app/src/MainFrame.cpp`, `tests/test_sidecar_restart.cpp`, `tests/acceptance/m7.5.steps`
- goal: Let the user opt in to their claude.ai MCP connectors (Gmail, Drive, ...) when the app uses their local login.
- spec:
  1. `Settings::useClaudeAiConnectors()` / `setUseClaudeAiConnectors(bool)`, stored in `wxConfig`, default off.
  2. `Settings::sidecarEnv()` sets `ENABLE_CLAUDEAI_MCP_SERVERS=true` only when both the local login and this setting are on. Otherwise it stays `false`, as today. API-key mode never loads connectors.
  3. Settings dialog: a checkbox "Use my claude.ai connectors (Gmail, Drive, ...)" under the local login checkbox, with one line of help: "Lets the assistant use the connectors on your claude.ai account. It asks before each use." The checkbox is enabled only while "Use my local Claude Code login (developer)" is checked, and follows it live in the dialog. Its stored value is kept when the local login is turned off.
  4. Changing the setting restarts the sidecar on OK, like the other settings (M7.2): include it in the "setting changed" comparison in `MainFrame`.
  5. No sidecar change. Connector tools are not in `READ_ONLY_TOOLS` (`sidecar/reader_sidecar/chats.py`), so every connector tool call already goes through the permission dialog (M5.4).
  6. No "Claude Code" in the new UI text (R4).
- done when:
  - [ ] Unit tests: the setting defaults off and round-trips through wxConfig; `sidecarEnv()` gives `ENABLE_CLAUDEAI_MCP_SERVERS=false` for API-key mode (setting on or off) and for local login with the setting off, and `true` for local login with the setting on.
  - [ ] The dialog shows the checkbox, disabled while the local login is off and enabled once it is checked (screenshots).
  - [ ] Turning it on and pressing OK restarts the sidecar with `ENABLE_CLAUDEAI_MCP_SERVERS=true` (fake sidecar records its env, as in M7.2).
  - [ ] `ctest` passes and the M7.1 and M7.2 acceptance steps do not regress.
