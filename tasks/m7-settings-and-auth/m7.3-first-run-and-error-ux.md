- notes:
  - Error mapping lives in `chat/SetupBanner.h` (`errorAction`, `errorClosesChat`, `needsSetup`) and ChatPanel acts on it, reusing the M5.2 reopen path for unknown_chat, cli_missing and process. auth shows the banner and an inline "API key rejected: ..." line; the banner goes away after OK in Preferences (Cancel keeps it). Retry re-sends the last prompt and shows it again as a user message. A sidecar exit (EVT_SIDECAR_DOWN) now reads "Agent stopped, restarting… (reason)".
  - Open Settings queues `wxID_PREFERENCES` to the frame, so it is the same dialog and save path as Edit > Preferences.
  - Carried (M4.5) rate limit: when a turn reported a rejected RateLimitEvent (or AssistantMessage.error) and then a non-error result with no text_delta or tool_use, the sidecar sends `error` of that kind instead of `result`. A reply that did stream output keeps its result (the request may have gone through on overage). PROTOCOL.md says so.
  - Carried (M4.5) crash after interrupt: the sidecar still sends `interrupted` (M4.4 tests require the chat to keep taking prompts), but it disconnects the dead client and sets `options.resume` to the last session_id it saw, so the next prompt connects a new CLI on the same session instead of failing with `process`.
  - Carried (M7.1) KeyTester: `SidecarClient::shutdownInBackground()` closes stdin and returns; a detached thread sends SIGTERM/SIGKILL after 3 s/1 s unless wx has seen the exit. KeyTester uses it. `restart()` and app exit still use the blocking `shutdown()` (the M7.2 restart test relies on the order), so a save that does restart can still block until the old sidecar exits; the real sidecar exits promptly on EOF.
  - Carried (M7.1) double error box: SystemKeyStore wraps wxSecretStore Save/Load/Delete in wxLogNull, so only the dialog's own message shows. Not reproduced here (needs a secret service that fails a save).
  - Carried (M7.2) Preferences OK restarts only when the model, the developer login or the stored key changed (or the assistant is unavailable, so a reinstalled sidecar can be picked up). A failed restart shows "Assistant unavailable: reader-sidecar not found" in the status bar and a red notice in the chat, and Send is disabled.
