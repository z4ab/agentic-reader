  1. Store the API key with `wxSecretStore::GetDefault()`, service `"agentic-reader"`, username `"anthropic-api-key"`. If `IsOk()` is false (for example, no secret service on Linux), show why in the dialog and do not fall back to plain-text storage.

  5. Open it from Edit > Preferences (macOS: the app menu Preferences item via `wxID_PREFERENCES`).

- notes:
