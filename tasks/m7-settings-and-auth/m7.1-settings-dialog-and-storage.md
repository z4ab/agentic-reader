# M7.1 Settings dialog and storage

- status: done
- depends: M5.1
- files: `app/src/settings/Settings.{h,cpp}`, `app/src/settings/SettingsDialog.{h,cpp}`, `app/src/MainFrame.cpp`
- goal: One place for the API key, model, and dev login toggle.
- spec:
  1. Store the API key with `wxSecretStore::GetDefault()`, service `"agentic-reader"`, username `"anthropic-api-key"`. If `IsOk()` is false (for example, no secret service on Linux), show why in the dialog and do not fall back to plain-text storage.
  2. Store the model (free text, default empty, meaning the SDK default) and "Use my local Claude Code login (developer)" (default off) in `wxConfig`.
  3. Dialog: masked key field with a "Show" toggle, a "Test key" button, the model field, and the dev checkbox with a one-line warning that it is for personal use only.
  4. "Test key" starts a temporary sidecar with the entered key and sends one `new_chat` + `prompt "ping"`. It reports OK or the error kind.
  5. Open it from Edit > Preferences (macOS: the app menu Preferences item via `wxID_PREFERENCES`).
- done when:
  - [x] Manual: save a key, restart, and the key is still there. The key never shows up in `wxConfig` files or logs (grep for it).
- verify: manual run plus `grep -r <first 10 chars of key>` over the config dir and the log dir returns nothing.

- notes:
  - human check: on a desktop with a secret service, open Edit > Preferences, save a key, restart the app, reopen Preferences: the masked key is there. Then `grep -r <first 10 chars> ~/.config/agentic-reader.conf ~/.agentic-reader/logs` returns nothing.
  - human check: "Test key" with a real valid key reports "The key works." and a bad key reports error kind "auth". It sends one short prompt.
  - wx 3.3 loads the system `libsecret-1.so.0` at run time (dlopen), which brings the system GLib beside the app's static vcpkg GLib. Save, load, and erase work, but each store load prints one `GLib-GObject-CRITICAL g_object_unref` line and leaks the SecretService object. Packaging (M8.2) must ship or depend on libsecret, or the dialog shows "cannot be stored securely".
  - Locations: wxConfig writes `~/.config/agentic-reader.conf` (group `[Agent]`, `Model`, `UseLocalLogin`). Logs go to `~/.agentic-reader/logs/`: `sidecar.log` and `sidecar-keytest.log` for Test key.
  - Test key sends `open_project` (an empty temp folder) before `new_chat`, since the protocol answers `no_project` otherwise. It sets `ANTHROPIC_API_KEY` and removes `ANTHROPIC_AUTH_TOKEN` and `CLAUDE_CODE_OAUTH_TOKEN` for that sidecar only, denies any permission request, and gives up after 60 s.
  - For M7.2: `SidecarClient::setEnvironment()` applies env changes at each spawn. The main sidecar still gets the app env unchanged.
  - The dialog calls `Raise()` once shown. Without a window manager (Xvfb) GTK never activated it and Tab stopped moving focus.
  - The checkbox label "Use my local Claude Code login (developer)" comes from spec item 2. M7.4 (branding audit) should review it against R4.
  - carried: (M1.1) The vcpkg libsecret port fails to install here: meson installs the secret-tool bash completion into /usr/share/bash-completion/completions (permission denied) because the system bash-completion.pc is found. M1.1 therefore uses wxwidgets without the `secretstore` feature. To enable wxSecretStore, add a libsecret overlay port under `vcpkg-overlays/` that disables bash completion, then request `wxwidgets[secretstore]`.
