# M8.4 macOS app bundle

- status: todo
- depends: M8.1, M7.4
- files: `app/CMakeLists.txt` (bundle settings), `packaging/macos/Info.plist.in`, `packaging/macos/entitlements.plist`, `packaging/macos/sign_and_notarize.sh`
- goal: A signed, notarized `.app` in a `.dmg`.
- spec:
  1. `MACOSX_BUNDLE` with `Info.plist` (bundle ID matches the app ID decision, PDF document type).
  2. Copy dylibs into `Contents/Frameworks` and fix install names (`fixup_bundle` or `install_name_tool`). Put the sidecar folder in `Contents/Resources/reader-sidecar/`.
  3. Sign everything inside-out with the hardened runtime. The sidecar's bundled CLI needs signing too.
  4. Notarize with `notarytool` and staple. This needs an Apple Developer account. Credentials are CI secrets, and the step is skipped when they are absent.
  5. Build the `.dmg` with `hdiutil`.
- done when:
  - [ ] An unsigned build runs locally on macOS end to end.
  - [ ] With credentials, Gatekeeper accepts the notarized `.dmg` on a clean machine.
- verify: CI artifact plus a manual run on a Mac.
- evidence:
- notes: Notarization needs the user's Apple account (`owner: human` for that step).
