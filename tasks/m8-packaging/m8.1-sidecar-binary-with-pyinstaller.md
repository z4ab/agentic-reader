# M8.1 Sidecar binary with PyInstaller

- status: todo
- depends: M8.0, M4.5
- risks: R1
- files: `sidecar/reader-sidecar.spec`, `sidecar/scripts/build_binary.py`, `.github/workflows/build.yml`
- goal: A single sidecar executable per OS that needs no Python on the user's machine.
- spec:
  1. Find where the SDK wheel stores its bundled CLI (inspect the installed package). Include it with PyInstaller `datas`/`binaries` and keep its executable bit.
  2. Confirm the SDK finds the bundled CLI from inside the frozen app. If it does not, pass `cli_path` in `ClaudeAgentOptions`, resolved from `sys._MEIPASS`.
  3. Use one-folder mode (`--onedir`), not one-file. This avoids extracting a large binary on every launch.
  4. CI builds the sidecar on all three OSes and uploads it as an artifact.
  5. If M8.0 chose download-on-first-run, implement that here instead: on startup, download the platform wheel into the user data dir and set `cli_path` to it, with a progress message to the app.
