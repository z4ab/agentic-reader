- depends: M2.1
- files: `app/src/pdf/PdfView.{h,cpp}`, `app/src/pdf/PageLayout.{h,cpp}`, `tests/test_page_layout.cpp`, `app/src/MainFrame.cpp`
- goal: Continuous vertical scroll of all pages in the center pane.
- spec:
  1. `PageLayout` is pure math with no wx windows: given page sizes in points, zoom, viewport width and DPI scale, compute each page's rect in virtual pixels. Pages are centered horizontally with a 12px gap between them.
  2. `PageLayout::pageAt(y)` and `visiblePages(viewRect)`.
  3. `PdfView : wxScrolledCanvas`. Set the virtual size from `PageLayout`. In `OnPaint`, draw a grey background, a white page rect with a 1px border for every visible page, and the page bitmap when cached.
  4. For now, render synchronously on paint into a simple `std::map<int, wxBitmap>`. M2.3 replaces this.
  5. HiDPI: multiply render scale by `GetDPIScaleFactor()` and draw the bitmap scaled back so text stays sharp.
  6. `MainFrame` replaces the center placeholder with `PdfView`. Temporarily open the path given as `argv[1]`.
