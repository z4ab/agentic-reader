# M2.1 PdfDocument wrapper

- status: done
- depends: M1.2
- files: `app/src/pdf/PdfDocument.{h,cpp}`, `tests/test_pdf_document.cpp`
- goal: One class that owns a poppler document and answers everything the view needs.
- spec:
  1. `static std::unique_ptr<PdfDocument> open(const std::filesystem::path&, const std::string& password, std::string& error)`. Report "not a PDF", "file not found", and "password required" as distinct errors. Detect locked documents with `document::is_locked()`.
  2. `int pageCount() const`.
  3. `wxSize2D pageSizePts(int page) const` using `page::page_rect(crop_box)` (media_box until M2.2). Account for `page::orientation()` so rotated pages report swapped sizes.
  4. `wxImage renderPage(int page, double scale) const`: render at `72 * scale` dpi with antialiasing and text hinting on. Convert `poppler::image` (`format_argb32`, BGRA in memory on little-endian) to `wxImage` RGB + alpha. Respect `bytes_per_row()`, which can exceed `width * 4`.
  5. Store the path. Expose `path()`.
  6. Not thread-safe. Say so in a header comment. M2.3 gives each thread its own instance.
- done when:
  - [x] Tests cover: page count, page size of `sample.pdf`, render size equals `ceil(pts * scale)`, a pixel known to be white is white, the three error cases.
- verify: `ctest --test-dir build -R pdf_document`
- evidence: impl commit 4f42527. `ctest --test-dir build -R pdf_document`: 1/1 passed (doctest 11 cases, 81 assertions). Full `ctest`: 3/3 passed (pdf_document, poppler, smoke).
- notes:
  - deviation: `wxSize2D` does not exist in wxWidgets 3.3.3 (vcpkg). `pageSizePts()` returns `wxRealPoint` (x = width, y = height). Accepted by the orchestrator.
  - Page indices are 0-based. Invalid pages give `wxRealPoint(0, 0)` and an invalid `wxImage`.
  - `open()` passes the password as both user and owner password. A wrong password leaves poppler's document locked, which reports "password required". A missing path or a non-regular file (directory) reports "file not found".
  - `renderPage()` passes explicit width and height (`ceil(pts * scale)`) to `render_page` because poppler rounds its default size to nearest. Size comes from the crop box, which is what poppler renders (switched from the media box in M2.2).
  - Paths reach poppler as `path.string()`. Non-ASCII paths on Windows may fail to open. Check in CI once Windows runs PDFs.
  - poppler prints parse errors ("May not be a PDF file", "Incorrect password") to stderr on failed opens. Harmless, can be silenced with `poppler::set_debug_error_function` later.
  - carried: (M1.2 review) `app/src/main.cpp` logs `poppler::version_string()` with `wxLogDebug` only to keep poppler-cpp in the app link. `wxLogDebug` compiles out at `wxDEBUG_LEVEL=0`. Once the app uses `PdfDocument`, that line is no longer needed. Left for M2.2: the app does not use `PdfDocument` yet, so `main.cpp` is unchanged.
