# M2.1 PdfDocument wrapper

- status: todo
- depends: M1.2
- files: `app/src/pdf/PdfDocument.{h,cpp}`, `tests/test_pdf_document.cpp`
- goal: One class that owns a poppler document and answers everything the view needs.
- spec:
  1. `static std::unique_ptr<PdfDocument> open(const std::filesystem::path&, const std::string& password, std::string& error)`. Report "not a PDF", "file not found", and "password required" as distinct errors. Detect locked documents with `document::is_locked()`.
  2. `int pageCount() const`.
  3. `wxSize2D pageSizePts(int page) const` using `page::page_rect(media_box)`. Account for `page::orientation()` so rotated pages report swapped sizes.
  4. `wxImage renderPage(int page, double scale) const`: render at `72 * scale` dpi with antialiasing and text hinting on. Convert `poppler::image` (`format_argb32`, BGRA in memory on little-endian) to `wxImage` RGB + alpha. Respect `bytes_per_row()`, which can exceed `width * 4`.
  5. Store the path. Expose `path()`.
  6. Not thread-safe. Say so in a header comment. M2.3 gives each thread its own instance.
- done when:
  - [ ] Tests cover: page count, page size of `sample.pdf`, render size equals `ceil(pts * scale)`, a pixel known to be white is white, the three error cases.
