# M2.5 Opening files

- status: done
- depends: M2.4
- files: `app/src/MainFrame.{h,cpp}`, `app/src/pdf/PdfView.cpp`
- goal: Users can open PDFs every common way, and bad files fail cleanly.
- spec:
  1. File > Open (Ctrl+O) with a `*.pdf` filter.
  2. Drag and drop a PDF onto the window (`wxFileDropTarget`).
  3. A command-line path argument (replaces the M2.2 temporary code).
  4. Encrypted PDF: prompt for the password with `wxPasswordEntryDialog`. Retry on a wrong password. Cancel closes the attempt.
  5. Invalid or missing file: `wxMessageBox` with the error from `PdfDocument::open`. The view keeps the previous document.
  6. File > Recent (`wxFileHistory`, 10 items, persisted with `wxConfig`).
- done when:
  - [x] All three open paths work.
  - [x] An encrypted PDF opens after the right password.
  - [x] A renamed `.txt` file shows an error and nothing crashes.
- verify: manual run with sample, encrypted, and invalid files.

- notes:
  - carried: (M2.3) `RenderWorker` opens its own `PdfDocument` with an empty password. Pass the password the user entered to the worker for encrypted files.
  - Done: the password loop lives in GUI-free `pdf/OpenPdf.{h,cpp}`; MainFrame's prompt is a `wxPasswordEntryDialog` and says "The password is incorrect" on retries. `PdfView::openFile` became `setDocument(doc, password)`; the password goes to `RenderWorker` (carried note handled). The command-line file opens through `CallAfter` once the window is shown, so its error box has a visible parent. Drops on the PDF pane queue `EVT_PDF_FILE_DROPPED`, so the drop finishes before any dialog. Recent is a `wxFileHistory` (10 items, IDs from `wxID_HIGHEST + 1`) in wxConfig group `/RecentFiles`, saved and flushed after each change; a Recent entry whose file is gone is dropped after its error box.
  - Opening another PDF from the folder already open keeps the chat; a PDF from another folder calls `ChatPanel::openProject` with that folder (M5.2 behaviour until M6 projects).
  - wxGTK's `wxFileHistory` also adds opened files to GTK's recent-files list (`~/.local/share/recently-used.xbel`). That is stock wx behaviour.
  - Cloud build: built with `-DCMAKE_PREFIX_PATH=$HOME/sysdeps` (wx 3.3.3, Ubuntu poppler-cpp 24.02), not vcpkg. No live Claude checks were needed.
