# M10.5 Fullscreen presentation mode

- status: todo
- depends: M10.3
- files: `app/src/MainFrame.{h,cpp}`, `app/src/pdf/PdfView.{h,cpp}`, `tests/acceptance/m10.5.steps`
- goal: F11 shows only the document, for presenting or reading slides.
- spec:
  1. F11 toggles fullscreen: `ShowFullScreen(true, wxFULLSCREEN_ALL)`, unsplit the project and chat panes, hide the toolbar. Works in both modes.
  2. Esc or F11 restores the panes at their previous sash positions and the toolbar. Esc exits fullscreen unless something else handles Esc first (a modal dialog, or a chat Esc-to-stop key if one exists then).
  3. SinglePage fullscreen paints a black background around the slide.
  4. Ctrl+Shift+A ("Ask about selection") leaves fullscreen first so the chat pane is visible.
  5. A View menu item "Fullscreen" shows F11.
- done when:
  - [ ] F11 in hides both panes and the toolbar, black around the slide in SinglePage (screenshot).
  - [ ] F11 or Esc out restores the same pane widths (screenshots before and after).
  - [ ] Ctrl+Shift+A in fullscreen leaves fullscreen and fills the chat input.
  - [ ] `ctest` passes and existing acceptance steps do not regress.
- verify: `ctest`, then `scripts/shot.sh -o <repo>/.verify/m10.5/impl -s tests/acceptance/m10.5.steps -- ./build/app/agentic-reader tests/data/slides-16x9.pdf`.
