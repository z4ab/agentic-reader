- status: done

- files: `app/src/pdf/PdfView.{h,cpp}`, `tests/acceptance/m10.4.steps`
- goal: Text selection and find work on slides the same way they work in Continuous.
- spec:
  1. `PdfView::revealRect(int page, RectPts rectPts)` scrolls a rect in page points into view with a 24px margin. In SinglePage it first shows that page and keeps the zoom. Find next/prev use it.
  2. In SinglePage a drag selects within the shown page only. The selection survives page flips, is drawn only when its page is shown, and Ctrl+C copies it from any page.
  3. Find highlights matches on the shown page. Next and prev flip to the slide holding the match and wrap at the ends.
  4. Continuous behaviour is unchanged.
